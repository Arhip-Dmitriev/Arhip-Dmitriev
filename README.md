### Selected Work

**[ArchytasZX](https://github.com/Arhip-Dmitriev/ArchytasZX)** — Python engine for the qufinite ZXW-calculus that rewrites and proves diagram identities with qudit dimension and system size kept symbolic. Exact symbolic algebra, a constraint-guarded subgraph matcher, and a certificate-emitting rewrite engine, all written from scratch. Qudit identity families are proven for all dimensions and sizes by induction over bang-box multiplicity, and each proof is exported as a Lean 4 theorem that Lean checks with no unproved axioms.

**[DiracULA](https://github.com/Arhip-Dmitriev/DiracULA)** — Dirac-notation language, REPL, and Python API that derives quantum algorithm results by symbolic path-sum rewriting, never by simulation, so every state and measurement distribution is one closed form valid for all system sizes and qudit dimensions. Closed forms for GHZ, Deutsch-Jozsa, Grover, and Shor order finding, each certifiable against a mirrored Lean 4 normaliser.

**Quantum embedding error proxy** — Using ML trained on HPC procured sample geometry and error data to learn about and predict the relation between fundamental molecular properties, embedding cut-offs, and the produced boundary error.

**Full-stack accounting and management platform** — Production system serving approximately one hundred employees at Beeline Group, built with PostgreSQL, Express, React, and Next.js, including audits of accounting calculation correctness and encrypted storage against several international compliance standards.

**Rare books collection database** — Web application digitizing a catalog of three hundred or more rare volumes, with search and filtering by title, author, date, and catalog identifier, built from requirements gathered with faculty and visiting researchers.
